A command-line tool for memorizing text-based content, using a spaced repetition system.

Features:
- Use content from your anki account, or interact purely with text files
- Optionally, display productive-looking output in the terminal, above the interactive prompt
   - Useful for filling moments at work where you need to wait for a process to finish, but you
      don't want to distract yourself with a different task, application, or addictive algorithmic feed
- Always has content to review
    - Even when Anki thinks you're done
    - Even when you're offline
